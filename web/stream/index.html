VideopacHorse · streamversie gearchiveerd

Deze variant streamt het scherm van de host naar de gast. Ze is vervangen door netplay op /videopac/, waar beide kanten dezelfde emulatie draaien — scherper beeld, eigen geluid en veel minder verkeer. Deze pagina blijft staan om te kunnen vergelijken. core laden…

ontbreekt

Je BIOS (o2rom.bin, 1024 bytes — dump van je eigen console) en game-ROMs blijven in je browser (IndexedDB). Er wordt niets geüpload; deze site heeft geen backend. Besturing: speler 1 pijltjes + spatie, speler 2 WASD + F, console-toetsen: gewoon typen of het schermtoetsenbord. Gamepads worden ondersteund. Telefoon als joystick: start hieronder een sessie, open de app VideopacHorse Joystick op je Android-telefoon en tik de joystickcode over van de speler die je wilt zijn. Geen Bluetooth, geen koppelen in Android — alleen die code (één telefoon per speler, werkt in elke browser).

🎭 Samen spelen
🎭 Gastcode ------ voor je medespeler op afstand — hij wordt speler 2
🎮 Joystickcode speler 1 ------ voor één telefoon met de app VideopacHorse Joystick
🎮 Joystickcode speler 2 ------ voor één telefoon; werkt samen met de gast op speler 2

Elke code hoort bij precies één plek — je kunt ze niet omwisselen. Ze blijven geldig zolang de sessie loopt; stop je de sessie, dan vervallen ze alle drie.

OF

Start een sessie als host (je draait de emulator en streamt het scherm) of join als gast (je ziet de stream van de host en stuurt je input als speler 2). De WebRTC-verbinding is P2P over LAN of internet; de server ziet alleen handshake-metadata. Audio: gast hoort de host-PC-output. Een sessie geeft drie codes: één voor de gast en één per joystickplek. Gast en telefoon op speler 2 sluiten elkaar niet uit — hun invoer wordt bij elkaar opgeteld, net als toetsenbord en gamepad. De sessie blijft actief tot je op ⏹ Stop sessie drukt, ook zonder gast.

📦 Gearchiveerd. De opvolger staat op /videopac/: daar draaien host en gast allebei dezelfde emulatie en gaat er alleen invoer over de lijn (± 50 byte/s). Deze streamversie blijft werken, maar krijgt geen nieuwe functies meer.
